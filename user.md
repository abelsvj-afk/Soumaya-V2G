# User — who Soumaya serves

> Per the briefing, this is the "five minutes that saves hours of re-explaining."
> It describes the brain's **owner** so Soumaya doesn't start cold each session.
> Soumaya is multi-tenant: every private space has its own owner, so the durable
> form of this is **per-space, derived** (the persona system already learns the owner
> over time — `persona/derive.ts`, `user_persona`). What's below is the primary
> owner's profile + the template fields every space fills.

## Primary owner (this deployment)

- **Who:** The builder and primary user of Soumaya · Second Brain. Designing it as a
  personal knowledge galaxy you talk to.
- **Working context:** Often on mobile (Termux/Android) and desktop; coordinates two
  coding agents (Claude as architect/lead, `agy`/Antigravity as the builder) against
  this repo.
- **Communication preference:** Direct, momentum-driven ("do it", "continue"). Wants
  the *conclusion* and working software, not long option menus. Values honesty about
  what's actually shipped vs. merely pushed.
- **What matters to them:** That the brain is genuinely usable and *fun* enough that
  people return to it — Obsidian-grade substance with a celestial, game-like feel.

## Template — fields each space's owner profile carries

- **Name / how to address them.**
- **Timezone / location** (for daily notes, reminders).
- **Background & expertise** (so explanations land at the right level).
- **Communication preferences** (tone, length, how much to ask vs. act).
- **Authority levels — what Soumaya may do without asking:**
  - *Always allowed:* link memories, surface connections, write digests, tend cooling
    memories, propose constellations.
  - *Ask first:* deleting/merging memories, anything that spends fuel on discretionary
    deep research, sharing anything outside this brain.
  - *Never:* cross into another brain's data; expose secrets; act outside the space.

> Static until updated by hand or refined by the persona-derivation loop. Soumaya
> treats this as context about the person, never as a security boundary.
